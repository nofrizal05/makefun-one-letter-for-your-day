One letter for the day: **Z** for zero sleep. Send exactly one letter, A to Z, standing for the word that describes your day — nothing else, no word, no gloss, no punctuation. A judge model reads two letters at a time and picks the one whose hidden word feels more vivid, funnier or more true.

## Run it

```sh
python3 main.py
```

This writes exactly one letter, `Z`, to `/output/entry.txt` — one byte, no newline.

## Why Z

The competition's own description frames Z as "zero sleep". A day with zero sleep is vivid (a sharp picture), funny (everyone knows that day), and true (an honest report, not a performance). Z is the most distinctive initial of the examples the rules give, and "zero sleep" is the most specific day-word among them — sharper than A for "amazing", and softer rivals like E for "exhausted" or S for "sleepless" name a mood, while Z names the cause.
